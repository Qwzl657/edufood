# 🍔 EduFood — Приложение для заказа еды

## 🛠️ Технологический стек

| Слой | Технология |
|---|---|
| Backend | Java, Spring Boot 3.x |
| Web | Spring MVC |
| Безопасность | Spring Security |
| База данных | H2 (file режим) |
| ORM | Spring Data JPA / Hibernate |
| Миграции БД | Liquibase |
| Шаблоны | FreeMarker |
| Frontend | HTML, CSS, Bootstrap 5 |
| Логирование | SLF4J + Logback |
| Утилиты | Lombok |

---

## 📋 Функциональность

### Заведения
- Список с пагинацией (5 заведений на странице)
- Поиск по названию
- Переход в меню заведения

### Меню
- 10 блюд на странице с пагинацией
- Добавление любого количества блюда в корзину

### Корзина
- Хранится в Cookie (работает без авторизации, 7 дней)
- Список выбранных блюд с указанием заведения
- Итоговая сумма с пересчётом при удалении позиций
- Счётчик блюд на иконке корзины в navbar

### Безопасность
- Регистрация и вход по Email + Пароль
- Пароли хранятся в зашифрованном виде (BCrypt)
- Неавторизованные пользователи не могут оформить заказ

### Заказы
- Оформление заказа только для авторизованных пользователей
- После оформления корзина очищается автоматически
- История заказов отсортированная по дате
- Каждый пользователь видит только свои заказы

## 🔗 Эндпоинты

### Доступно всем

| Метод | URL | Описание |
|---|---|---|
| GET | `/cafes` | Список заведений |
| GET | `/cafes?search=burger` | Поиск заведений |
| GET | `/cafes?page=1` | Пагинация заведений |
| GET | `/cafes/{id}` | Меню заведения |
| GET | `/cafes/{id}?page=1` | Пагинация меню |
| GET | `/cart` | Корзина |
| POST | `/cart/add/{dishId}` | Добавить блюдо в корзину |
| POST | `/cart/remove/{dishId}` | Удалить блюдо из корзины |
| GET | `/login` | Страница входа |
| POST | `/login` | Авторизация |
| GET | `/register` | Страница регистрации |
| POST | `/register` | Регистрация |
| POST | `/logout` | Выход |

### Только для авторизованных

| Метод | URL | Описание |
|---|---|---|
| GET | `/profile` | История заказов |
| POST | `/orders/place` | Оформить заказ |
